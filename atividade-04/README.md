## Sobre

Projeto 02 da lista de projetos do bootcamp: classificação de frutas, usando o dataset do Kaggle:
https://www.kaggle.com/datasets/icebearogo/fruit-classification-dataset

O dataset original tem 100 classes; o grupo optou por trabalhar com 10 classes.
